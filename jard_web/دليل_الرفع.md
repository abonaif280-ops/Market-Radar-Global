# أداة الجرد — دليل الرفع على PythonAnywhere

## محتويات الملف المضغوط
| الملف / المجلد | الوظيفة |
|---|---|
| `jard_server.py` | الخادم (تسجيل الدخول، الصلاحيات، الحفظ في قاعدة البيانات) |
| `jard_models.py` | جداول قاعدة البيانات |
| `jard_config.py` | **الإعدادات** (بيانات MySQL) — الملف الوحيد الذي قد تعدّله |
| `app/jard.html` | واجهة الأداة |
| `templates/` | صفحات الدخول والمستخدمين وكلمة المرور |
| `static/` | الأيقونة وملف العمل بدون إنترنت |
| `manage.py` | أوامر مساعدة (استرجاع حساب المدير، نسخة احتياطية) |
| `wsgi_pythonanywhere.py` | للحل 1: موقع مستقل |
| `wsgi_add_to_existing_site.py` | للحل 2: إضافة الأداة داخل موقع موجود |

---

## الخطوة 1: إنشاء الحساب
1. ادخل https://www.pythonanywhere.com وأنشئ حسابًا (الحساب المجاني يكفي للبداية).
2. **اسم المستخدم سيظهر في رابط الموقع** (`اسمك.pythonanywhere.com`)، فاختر اسمًا محايدًا.

## الخطوة 2: رفع الملفات
1. افتح تبويب **Files** وارفع الملف `jard_web.zip` إلى المجلد `/home/اسمك/`.
2. افتح تبويب **Consoles** ← **Bash**، واكتب:
```bash
unzip jard_web.zip
pip3 install --user -r jard_web/requirements.txt
```
> إذا ظهر خطأ في تثبيت `mysqlclient` فتجاهله، لأنه مثبّت مسبقًا على PythonAnywhere.

## الخطوة 3: قاعدة البيانات (MySQL) — مستحسنة
> إذا تخطيت هذه الخطوة تعمل الأداة على قاعدة SQLite داخل مجلد `jard_web/data`، وهي مناسبة للتجربة والأعداد الصغيرة.

1. افتح تبويب **Databases** ← حدّد كلمة مرور MySQL واحفظها.
2. في خانة **Create a database** اكتب `jard` ثم **Create**، فتصبح القاعدة باسم `اسمك$jard`.
3. من تبويب **Files** افتح `jard_web/jard_config.py` وعدّل الأسطر الأربعة:
```python
MYSQL_USER = "اسمك"
MYSQL_PASSWORD = "كلمة مرور MySQL"
MYSQL_HOST = "اسمك.mysql.pythonanywhere-services.com"
MYSQL_DB = "اسمك$jard"
```
4. احفظ الملف. **الجداول تُنشأ تلقائيًا** عند أول تشغيل.

## الخطوة 4: اختر طريقة التشغيل
> إذا كان حسابك وصل للحد الأقصى من المواقع (رسالة **Upgrade to add a new web app**) فاستخدم **الحل 2**.

### الحل 2: داخل موقع موجود (بدون حذف ولا ترقية) — الرابط: `رابط-الموقع/fp/`
1. تبويب **Web** ← اختر من القائمة اليسرى موقعًا موجودًا (يُفضَّل أقل المواقع أهمية).
2. في قسم **Code** اضغط على **WSGI configuration file**.
3. **لا تحذف شيئًا**؛ انزل إلى **آخر الملف** والصق محتوى `wsgi_add_to_existing_site.py`، وغيّر `USERNAME` إلى اسمك، واحفظ.
4. اضغط **Reload** لذلك الموقع.
5. الأداة على: `https://رابط-الموقع/fp/` والموقع الأصلي يعمل كما هو.
> ملاحظة: إذا كان الموقع الموجود يستخدم Python أقدم من 3.8 فاستخدم الحل 1.

### الحل 1: موقع مستقل

1. تبويب **Web** ← **Add a new web app** ← **Next** (أو احذف موقعًا قديمًا لا تحتاجه من زر **Delete** أسفل صفحته).
2. اختر **Manual configuration** (وليس Flask)، ثم اختر **Python 3.10** أو أحدث.
3. في نفس الصفحة، في قسم **Code**، اضغط على رابط **WSGI configuration file**.
4. **احذف كل محتواه** والصق محتوى الملف `wsgi_pythonanywhere.py`، ثم غيّر كلمة `USERNAME` إلى اسمك، واحفظ.
5. في قسم **Security** فعّل **Force HTTPS**.
6. ارجع لـ `jard_config.py` واجعل `SECURE_COOKIES = True`، واحفظ.
7. اضغط الزر الأخضر **Reload** أعلى صفحة Web.

## الخطوة 5: أول دخول
1. افتح رابط الأداة (الحل 1: `https://الموقع.pythonanywhere.com` — الحل 2: `https://الموقع.pythonanywhere.com/fp/`).
2. ادخل بـ: اسم المستخدم **admin** وكلمة المرور **admin123**.
3. **غيّر كلمة المرور فورًا** من زر «🔑 كلمة المرور» لأن الموقع على الإنترنت.
4. من زر «👥 المستخدمون» أضف:
   - **رئيس اللجنة** (صلاحية: رئيس اللجنة) — له كل صلاحيات البيانات والتقرير النهائي.
   - **المندوبين** (صلاحية: مندوب) — يسجّلون الجرد والملاحظات فقط.

## على الجوال
- افتح الرابط من **Safari** (آيفون) أو **Chrome** (أندرويد)، وليس من داخل واتساب.
- لتظهر كتطبيق: **مشاركة ← إضافة إلى الشاشة الرئيسية**.
- **إذا انقطع الإنترنت في المستودع**: استمر في العمل عادي، فالبيانات تُحفظ في الجوال وتُرفع تلقائيًا عند عودة الشبكة.
- أعلى الشاشة تظهر حالة الحفظ: **✅ محفوظ** أو **⏳ جاري الحفظ** أو **📴 بدون اتصال**.

## نقل البيانات من النسخة القديمة (الملف المنفصل)
1. في النسخة القديمة: «استيراد وتصدير» ← **📦 تصدير الحزمة الكاملة**.
2. في الموقع (بحساب رئيس اللجنة أو المدير): «استيراد وتصدير» ← **📥 اختيار ملف للاستيراد** ← اختر الحزمة.
3. تُرفع الجهات والأصناف والملاحظات إلى قاعدة البيانات تلقائيًا.

## النسخ الاحتياطي
- من صفحة **👥 المستخدمون** ← **💾 نسخة احتياطية** (للمدير).
- أو من Bash console: `cd jard_web && python3 manage.py backup`

## حل المشاكل
| المشكلة | الحل |
|---|---|
| الموقع لا يفتح أو يظهر Error | تبويب Web ← **Error log** (آخر الأسطر توضح السبب) |
| نسيت كلمة مرور admin | Bash: `cd jard_web && python3 manage.py reset-admin` ثم **Reload**، فتعود إلى admin123 |
| خطأ اتصال بقاعدة البيانات | راجع الأسطر الأربعة في `jard_config.py` وكلمة مرور MySQL |
| الحساب المجاني توقّف | الحساب المجاني يتطلب الضغط على **Run until 3 months from today** في تبويب Web كل 3 أشهر |
| عدّلت ملفًا ولم يتغير شيء | اضغط **Reload** في تبويب Web |
