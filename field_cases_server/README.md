# الحالات الميدانية — نسخة الشبكة الداخلية

نسخة تعمل على سيرفر Windows داخلي، ويُدخَل إليها من المتصفح في أجهزة الكمبيوتر بالشبكة الداخلية.

- **الواجهة:** HTML وCSS من السيرفر نفسه، بالعربية ومن اليمين لليسار، بلا أي موارد من الإنترنت.
- **الخلفية:** Python (FastAPI)، وتعمل على منفذ يُحدَّد في `config.ini` (الافتراضي 8080).
- **قاعدة البيانات:** خارجية، **SQL Server أو PostgreSQL** حسب رابط الاتصال في `config.ini`. الجداول تُنشأ وتُرقّى بـ Alembic.

التثبيت: [docs/INSTALL_WINDOWS.md](docs/INSTALL_WINDOWS.md)

## التطوير
```bash
pip install -r requirements-dev.txt
cp config.example.ini config.ini        # اكتب [database] url
python manage.py init-db
python manage.py create-admin --username admin --full-name "مدير النظام"
python run_server.py                    # http://localhost:8080
python -m pytest                        # SQLite؛ أو FC_TEST_DATABASE_URL لقاعدة أخرى
```
