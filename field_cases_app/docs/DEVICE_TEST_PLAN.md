# خطة الاختبار على الأجهزة — iPhone و Android

تُنفَّذ على جهازين على الأقل (iPhone حقيقي + جوال Android حقيقي)، ويفضّل جهاز ثالث
لتجربة "موظف ← مشرف". سجّل لكل بند: ✅ نجح / ❌ فشل (مع لقطة شاشة ووصف).

**تجهيز**
- Android: ثبّت ملف APK التجريبي (من GitHub Actions ← `field-cases-android-test-apk`).
- iPhone: ثبّت من Xcode أو TestFlight (انظر `docs/RELEASE.md`).
- الأجهزة في **وضع الطيران** طوال الاختبار، إلا عند تجربة المشاركة عبر WhatsApp.

## 1. التشغيل والواجهة
| # | الخطوات | النتيجة المتوقعة |
|---|---|---|
| 1.1 | فتح التطبيق أول مرة | الرئيسية بالعربية من اليمين لليسار، بلا طلب أي إذن |
| 1.2 | تكبير الخط من إعدادات النظام | النصوص تكبر ولا تتداخل الأزرار |
| 1.3 | الوضع الداكن | الألوان مقروءة |
| 1.4 | تدوير الشاشة أثناء إدخال حالة | لا تضيع البيانات المدخلة |
